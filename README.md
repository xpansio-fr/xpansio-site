# xpansio.fr

Site d'Xpansio (Agnès Chabrier), hébergé sur GitHub Pages et publié automatiquement à chaque modification.

- `src/` : sources (contenu des pages dans `build.py`, styles dans `styles.css`, images dans `assets/`).
- `docs/` : site généré, c'est ce dossier que GitHub Pages met en ligne.

Pour régénérer le site après une modification des sources :

```
python3 src/build.py
```
